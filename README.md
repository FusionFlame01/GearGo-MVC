# GearGo

GearGo is a web app for a small equipment-rental business. Customers browse equipment (camping gear, power tools, event equipment) and request to rent it. Staff and managers manage equipment, rental requests and users.

## Get the source code

```bash
git clone https://github.com/FusionFlame01/GearGo-MVC
cd GearGo-MVC
```

## Requirements

- [.NET SDK](https://dotnet.microsoft.com/download)

## Start

```bash
dotnet restore
dotnet run --project GearGo
```

Open the address shown in the terminal (usually `https://localhost:xxxx`).

## Stop

Press `Ctrl + C` in the terminal where the app is running.
